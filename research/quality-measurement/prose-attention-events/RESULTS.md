## Next question, not a production change

Test whether an unresolved concern can remain active across intervening events, with later
evidence changing what receives attention, what is passed over, and when an interpretation is
reached. The representation would need to distinguish noticing, uncertainty and a concluded
meaning, and allow a concern to survive an anchor without being replaced. Derive those choices
from the supplied character and scene; no fixed narrative or biography is proposed.

That would require a fresh registered comparison and knowledge/fidelity controls. This batch
does not isolate the value of supplying states at all: there is no fresh trace-free baseline,
both conditions can use the same states spontaneously, and four writer draws share only one
derived trajectory. It cannot distinguish a weak rendering instruction from an unhelpful state
representation. No model judged, ranked or selected prose, and production code remains unchanged.
