# State-continuity admission: construction audit

This is call-free engineering under the operator's 2026-09-27 direction to establish one
admissible causal-damage test, or identify exactly why its proposed key fails. It audits
`binary-substitution.case-sham.v1`, the existing ecological state constructor. No reader
experiment, quality threshold or semantic admission is registered by this document.

Read `BRIEF.md`, `EPISTEMIC_GOVERNANCE.md` and
`plan/causal-salience-interventions.md`. The earlier book censuses and payoff construction
remain unchanged. No source store, manuscript, prompt or model is needed for these
counterexamples. Project-authored fixtures test a claimed construction guarantee; they are
not a sample of generated fiction or evidence about a reader's performance.

## Fixed checks

1. Build valid, uniquely located accepted state records around each of the constructor's
   allowlisted value substitutions. Exercise two sentence renderings. Keep anchor and target
   in separate scenes, with a complete intervening scene. Inspect the actual public packets
   for the anchor and interval text. Run a same-scene positive control separately so absence
   cannot be an always-failing search.
2. Enumerate all three-instant paths of a binary state. Constrain the first and last values
   using the two recorded assertions, before and after substitution. Report whether a
   consistent path exists. Repeat with an explicit no-change constraint as a positive
   control. This is a logical counterexample to deriving persistence from two equal values;
   it does not parse or assign truth to arbitrary prose. It also does not establish that a
   no-change sentence alone licenses admission on a natural manuscript.
3. Compare the six existing fingerprints against character-length and uppercase-letter
   deltas. On edited packets only, use the fixed rule `an all-uppercase word => sham,
   otherwise => damaged`, without consulting hidden keys or the story relation. Include an
   all-uppercase-state source as a destructive control on that rule's generality. Report
   ordinary-case and destructive-control results separately; never interpret the rule as
   reader accuracy or estimate an ecological shortcut rate.

All fixture inputs and renderers are in `audit.py`. The report keeps only counts, hashes,
identifiers and Boolean outcomes. Code checks a stronger construction claim by counterexample;
no empirical claim state is promoted and there is no paid arm to resume. These implementation
facts do not receive a research claim record (EPISTEMIC_GOVERNANCE.md, Claim records).

## Decision and scope

Missing required public evidence, a satisfiable damaged key without a persistence constraint,
or a separable control prevents this constructor from being advertised as model-eligible.
Construction availability and semantic admission must be separate. Keep diagnostic packets
inspectable and preserve historical artifacts; do not silently repair frozen experiments.

An alternative constructor would need a new version and independently established relation,
temporal/identity scope and intact consistency, full required context, a content-preserving
matched control, surface-shortcut attacks, and unseen book/implementation controls. Correct
span arithmetic alone cannot meet this contract. No change to production generation follows.

## Reproduce

Use the shared `runs/box.lock` procedure for sustained checks. Ordinary tests structurally
disable billing providers. The audit imports domain code only and opens no database.

```powershell
uv run python research/quality-measurement/state-admission-audit-20260927/audit.py
uv run pytest tests/test_state_admission_audit.py tests/test_salience.py -n 0
uv run python tools/check.py handoff
```

The first command prints deterministic JSON. `--out PATH` writes a new file and refuses to
overwrite existing evidence. Compare the output with `results.json`. Its source digests identify
the exact constructor, audit, contract and domain dependencies; future code changes require a
new result rather than relabelling these observations.
