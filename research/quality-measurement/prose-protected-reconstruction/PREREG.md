# Reconstruction with the original prose withheld

Operator-authorized test following paragraph revision; diagnostic, not quality qualification.
Conjecture: exposure to original prose encourages conservative reuse, even when incidental
information may be omitted. Test that exposure while keeping the writer task and protected
record identical. Two samples per condition cannot establish a general literary effect.

Use exactly the previous experiment's original chapter and researcher-authored 30-fact map,
not a candidate revision. Preserve each fact's identifier and description without alteration.
Remove source paragraph coordinates from both writer inputs; these are audit pointers, not an
outline for the new prose. Include the same ordered literal sequence, source conditions and
scene-division position in both. The literal sequence contains the same ten occurrences, with
its repeated awards and inline punctuation. The division follows the first private movement
award, as in the original. No model selects, extracts or edits the required record in this arm.

Both cells request complete chapter prose from the required record. Wording and paragraph
organization are free, with no word target, deletion quota, critic output or preferred example.
Do not invent incidents, backstory, named characters, quantities or rules. Preserve the
specified observations, inferences, causal relations and unresolved source ambiguities. The
control additionally receives the old chapter as optional reference prose; the treatment does
not. Apart from that appended block, actual prompts and systems must be identical. The control
may omit incidental information too. This avoids conflating source exposure with patch format
or an instruction to preserve every fact. Withheld prose contains both wording and incidental
information: this arm cannot separate those components or certify that the map was sufficient.

Reuse the signed-in ChatGPT Codex CLI transport, requested gpt-6-astra/high. Fixed order:
full-1, focused-1, focused-2, full-2. Four sequential calls maximum, no retry, redraw, fallback,

input + output + separately reported reasoning tokens reach 90000; cached input is already
included. An in-flight call may exceed the dispatch stop. Transport failure stops the arm;
literal or semantic failures remain visible without repair or another candidate.

committed after handoff before model calls. Verify withheld-task input excludes the original
paragraphs and provenance-only coordinates, rather than claiming there is no shared language:

usage, model-resolution uncertainty, literal checks and any deviations under ignored runs.
