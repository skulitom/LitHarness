# Protected reconstruction: opening inventory removed in both conditions

Four complete reconstructions of the same Chapter 1 were generated and read. All four omit
the original wage, elapsed examination time, smell, desk-total and handwriting inventory,
including both controls that received the old prose. Both withheld-prose outputs put the
changed-light event in paragraph 1; both reference-exposed outputs put it in paragraph 2,
after register description. This is a small observed pattern, not a qualified quality gain.
Withholding the original cannot receive exclusive credit for the inventory's disappearance.

Repeated rule interpretation remains in all four. New factual and grammatical problems also
appear. Reconstruction delivered more freedom than the preceding paragraph-patch task in
these samples, but several shared task features changed between experiments; that historical
comparison cannot isolate the cause. The original-exposure conjecture remains unqualified.

## Registered comparison

Registration commit b6cf896 preceded every call. Both conditions received exactly the same
30 protected facts from the preceding experiment, literal sequence, source conditions, scene
division and reconstruction instructions. Original paragraph coordinates were removed from
both inputs. The reference condition appended the original chapter as optional prose; the
other condition received no original chapter. Actual requests and configured system files
match the frozen inputs. Neither condition had a word target, patch format, counter target,
critic output, candidate-selection step or prescribed opening sentence.

Withholding removes both incidental information and phrasing. The researcher-authored record
retains source wording and requires several interpretations, including scheme recognition,
compliance, inactivity, arithmetic, the rule's omitted victim condition, rescue limits and
recall's unusual future cost. This was not an action-only input or an autonomous source
extractor, and it cannot establish whether the model would invent those interpretations
without being asked to preserve them.
