# Invention effort with fixed requests and downstream expansion

The operator asked to continue searching for the repetition solution. Previous Base64,
format and premise-batch experiments retained recurring story structures. This isolated
experiment changes native reasoning effort, a control not varied in those arms. The
conjecture is that low effort may alter the recurring choices made at medium effort;
neither direction nor a benefit is established. No production default changes here.

## Registered design

Draw three fresh 2,048-bit integers once and encode them using the existing v3 production
Base64 encoder. For each block use the exact ordinary six-premise batch request from
invention-contrast-20260911: same prefix, system, user text, schema, requested output limit
3,200, timeout 600, profile, tools and requested gpt-6-astra. Change only the provider's
reasoning_effort between low and medium. Keep the previous frozen source at d4ebdb5 and
the same native binary; verify the parent manifest and all its frozen files as well.

Generation order: low-1, medium-1, medium-2, low-2, low-3, medium-3. The reversal reduces
one simple order confound but three pairs cannot balance order completely or isolate
backend/time variation. Six premises within a response are correlated, not six trials.

Before dispatch, select one slot per block using
random.Random("invention-effort.v1:" + decimal_integer).randrange(6). Retain the draw
without rerolling, and use the same slot in both efforts. This external pseudorandom choice
is independent of output content, not model ranking or native sampling control.

After all six generation attempts, expand medium-3, low-3, low-2, medium-2, medium-1, low-1.
Every expansion uses normal medium effort and the unchanged production discovery renderer
with only the selected premise as its brief, third person, no writer and no second prefix.
Freeze and hash each dependent request before dispatch, retaining parent receipt and selected
text hashes. A malformed parent skips only its expansion; do not substitute another slot.

## Inspection and inference

Inspect no generated prose until the full registered sequence finishes or stops. Read all
36 premises and up to six expanded plans, retaining every first response and failure. Record
bounded paraphrases of protagonist, setting, initiating power action and continuing conflict,
with per-item hashes and word lengths. Literal searches locate passages, not semantic scores.
Inspect repeated causal sequences across batches and changes introduced during expansion;
different names or the omission of water from a short premise alone do not establish a cure.

If low effort retains the recurring professional-power, rescue, support/infrastructure or
institution-conflict structures, it has not removed those structures. If differences in the
selected premises disappear during normal expansion, changing invention effort alone has
not solved the downstream problem. If both controls vary similarly, credit neither with a
distinct benefit. Preserve differences and counterexamples as well as overlaps. These are
observations of this small sample, not quality judgments, effect estimates, training-distance
claims, tests of alignment causation or proof of a hidden sampling mechanism. Raw responses,
diagnostics and literature never become production instructions or reader feedback.

## Execution and bounds

Freeze runner, this protocol, parent manifest and its frozen files, dependency lock, trace
debugger, binary, seeds and prepared requests. Commit registration and pass the repository
handoff checker before model dispatch. Hold runs/box.lock after inspecting processes, with
one sustained job at a time. The provider uses existing subscription login and fresh isolated
sessions; no API keys, resets, fallback, live-provider tests, retries, redraws or implicit
resume. Stop before a call at 90,000 recorded tokens or twelve attempts; an in-flight call
may exceed the ceiling. Unknown usage, transport/auth/quota failure or frozen-file drift
stops the batch. Invalid output shape is retained without replacement.

The local configuration and captured launch must show identical requests per pair and
configuration equality except model_reasoning_effort. Verify distinct sessions and exact
selected briefs. This confirms requested controls, not backend implementation details.
