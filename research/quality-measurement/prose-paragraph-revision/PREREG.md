# Paragraph revision with selective information retention

Operator-authorized diagnostic of the actual criticized Chapter 1, not a quality-measurement
qualification. Conjecture: preserving every incidental detail may carry the overloaded account
through revision. Permission to omit or defer it may change the located inventory and repeated
interpretation while preserving consequential meaning. Four samples cannot establish a general
effect. The source, both instructions and analysis are fixed before calls; all outputs remain.

Use exactly the original 1924-word chapter in the existing prose-subtraction manifest, never a
preferred draft. Prepare a source-anchored protected-fact map before calls. Its construction is
researcher interpretation, not an autonomous fact selector or validated semantic instrument.
Read the full chapter and disclose source anomalies without silently fixing them. Common facts
protect events, causal relationships, viewpoint knowledge, consequential quantities, resource
transitions and endpoint. They do not require every incidental detail to remain on the page.
Keep system text literals, including inline awards, in their original sequence and multiplicity.
No corpus material, critic response, previous revision or reader output reaches the editor.

Both conditions receive identical original text, fact map, literal spans and editorial role.
The only changed instruction is whether all distinct information must remain explicit or
unprotected incidental information may be omitted/deferred. Both can rephrase, split and merge
paragraphs and consolidate repetition. Neither can invent incidents or background. There is no
word target, compression quota, phrase ban or model preference/selection. Codex CLI requests
gpt-6-astra/high, signed-in ChatGPT subscription only; no direct API or model fallback.

Two independent edits per condition, fixed order full-1, focused-1, focused-2, full-2. The
source is the common anchor; the two full-information edits show same-instruction variability.
Each returns JSON paragraph patches with original coordinates, reasons and declared omissions.
Code validates range identity, nonoverlap and shape, preserves unmentioned paragraphs exactly,
and reconstructs a separate inspection copy. Invalid patches remain rejected; no fuzzy repair,
partial application or redraw. A literal mismatch is retained and prominently marked failed,
not silently fixed. Transport failure stops further dispatch. A valid copy is not an accepted
manuscript and these checks cannot certify preserved meaning.

Read all four complete copies, every patch and declared omission against the original and
each protected fact. Record lost/changed causal information, agency, uncertainty, rule scope,
grammar, unsupported additions and retained problems. Inspect source paragraphs 1, 11-13,
23-26, 37-40, 44-47 and 51-52 in every copy; do not count only improvements. Record every
protected fact's resulting location or loss. Semantic failure prevents recommending adoption
of that copy; it does not trigger another edit. Distinguish source-inherited defects from new
ones. This is defect harvest, not a quality verdict or learned editor acceptance gate.

Run existing tells and register-gloss counters over the original and all inspection copies,
with raw counts and denominators, separate families and the same-prompt spread. Report long
sentences with a disclosed 35-word diagnostic threshold, not a quality bar. The counts measure
surfaces and are not supplied to generation, summed into quality or used to select an output.
New regexes for re-explanation/prolepsis are out of scope. Include a source/literal-preserving
actor-swap control demonstrating that lexical checks cannot certify semantic equivalence.

Four calls maximum, sequential. Stop before dispatch when input + output + separately reported
reasoning usage reaches 90000 tokens; cached input is already included. An in-flight call may
exceed that dispatch stop. No retries, health calls, API-key auth or quota resets. Freeze sources
and code hashes; commit registration and tests after handoff, before generation. Use ignored
runs roots for source/prose and commit only derived metadata, controls and findings. Keep the
production tells pass observational. No narrative is hardcoded into production or the runner.
