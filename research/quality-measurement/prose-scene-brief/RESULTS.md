# Scene-only brief and plan exposure: observed, unqualified

One fresh plan and eight fresh opening scenes were generated, all retained, and every scene
read in full in registered order. The compact task input did not eliminate the located
explanations, retrospective additions and rhetorical contrasts. Every condition began with
the trapped ankle and immediate response, including the extended-background controls.
That emergency was explicitly in the common core, so it is not an effect attributable to
compactness or plan omission. No quality ranking, efficacy or production qualification follows.

## Manipulation delivered

The fresh project-authored source was constructed once before generation. It contains a
328-word shared scene core plus writer instruction and a 781-word extended reference.
The common core supplies all current magical rules, quantities, goal and endpoint. Extended
reference adds biography, geography, work administration and tentative later-book material;
it is not a production-harness replay. It adds no rescue ability or current prerequisite.

One five-step plan was generated from the extended source. It required zero source corrections.
It uses a single activation, cuts on the ankle side of the held point, and ends on ankle
release about six seconds into the eight-second hold. No uniquely extended biography or
future fact was imported into the plan. Both planned cells received that identical sequence.
Both free cells received no plan, prior prose, critic output or reader response.

All eight use one activation and leave the other charge unspent. Free/full-2 changes the cut
side, then ends its hold before loosening the loop; the other free draws vary preparation and
assistance around the same broad method. The core strongly suggests a rope-hold/knife solution,
so plan omission is not a test of unconstrained plot exploration. Free-draft hold durations
are not always explicit enough to certify against the eight-second limit. Planned/focused-2
adds a wrist-thick rope, making its short cutting interval a plausibility concern, not a
demonstrated violation of a specified diameter or cutting-speed rule.

One concrete explanatory coherence problem appears in free/full-2 P25. It rejects the cut
between the held point and ankle on the grounds that it would leave the ankle attached to
the barge. Given the single loaded path described in that passage, either candidate cut
severs that connection; the difference is which side stays held and which can recoil. The
chosen river-side cut can work. The narration's reason for rejecting the other position does
not follow from its described layout. The full local reading records the schematic and
its assumptions; this is not a qualified automatic geometry or craft detector.

## Interpretation limits

This run does not establish a benefit from compactness, nor does it show that input design
cannot help. The prose still contains the targeted families in every cell. The emergency
opening appears in the extended controls too. The common premise, explicit starting emergency,
character's prior knowledge of the ability, short system instruction and available solution
all differ from the examination case. Comparing those cases cannot identify which change
matters or establish a quality improvement.

A discriminating next question would return to the examination premise and vary the opening's
immediate external task while holding other input boundaries fixed. That tests a scene-design
factor which this new case changes in common. It is a conjecture, not a recommendation to
make every book start with a rescue, an automatic editorial rule, or a result supported by
agent agreement. No further arm is dispatched as part of this registration.
